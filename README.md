# Johan Mireles — Portfolio

A single-page static site built from Johan's resume. There is no build step and no external JavaScript. These files are drafts only and have not been published.

## Local preview

Open `index.html` in a browser, or serve this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages (after review and approval)

Do not publish until the content has been reviewed.

1. Create a GitHub repository for the site. For a site at `https://<username>.github.io`, the repository is usually named `<username>.github.io`.
2. Add `index.html` and `style.css` from this folder (this README can stay with them).
3. In the repository settings, enable GitHub Pages from the default branch, root directory.

The site does not assume a GitHub username and does not link to any GitHub profile or repositories.
